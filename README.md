# rag-project-sydorenko

RAG-система для пошуку книжки за описом (сценарій «tip of my tongue»). Навчальний проєкт з дисципліни «Технології розробки гібридних систем штучного інтелекту».

## Сценарій використання

Читач пам'ятає сюжет, героїв чи окремі епізоди книжки, але не може згадати її назву й автора. Він описує книжку своїми словами, а система знаходить у корпусі найближчі описи та повертає назву, автора й уривок, що підтверджує відповідь.

Типовий запит: `A story about a group of boys stranded on an island who try to organise themselves and gradually turn savage`.

Обмеження системи:

- мова запитів, відповідей і корпусу лише англійська;
- один текстовий запит до 600 символів, діалог з уточненнями не передбачено;
- інтерфейс командного рядка, один запит дає одну відповідь;
- відповідь містить до трьох книжок, а для кожної назву, автора й рік (якщо вони є в записі) та уривок опису;
- система використовує лише відібрану підмножину корпусу, а якщо відповідного опису немає, повідомляє, що книжку не знайдено;
- рекомендації, оцінки книжок, пошук за обкладинкою чи цитатою з тексту та повні тексти книжок поза межами системи.

## Корпус даних

[CMU Book Summary Dataset](https://www.cs.cmu.edu/~dbamman/booksummaries.html) (D. Bamman, N. A. Smith, 2013). Це 16 559 книжок з описами сюжетів, назвою, автором, датою публікації та жанрами. Описи вилучено з Вікіпедії, метадані зіставлено з Freebase. Для проєкту планується підмножина орієнтовно з 5 000 книжок, остаточний обсяг буде визначено під час підготовки даних.

Ліцензія даних: [CC BY-SA 3.0 US](https://creativecommons.org/licenses/by-sa/3.0/us/), як заявлено авторами набору. Самі дані не зберігаються в репозиторії, їх завантажує окремий скрипт. Якщо похідні матеріали (підмножина, фрагменти текстів) будуть опубліковані, вони супроводжуватимуться тією самою ліцензією, посиланням на джерело та описом змін.

## Технологічний стек

| Компонент | Вибір |
|---|---|
| Мова програмування | Python 3.10 або новіший |
| Векторне сховище | Chroma |
| Модель ембедингів | BAAI/bge-small-en-v1.5 |
| Модель генерації | Llama 3.2 3B через Ollama |
| Інтерфейс | командний рядок, модуль argparse |

## Встановлення

1. Перевірте версію Python, потрібен 3.10 або новіший:

   ```bash
   python --version
   ```

2. Клонуйте репозиторій і перейдіть до його каталогу:

   ```bash
   git clone <URL_репозиторію>
   cd rag-project-sydorenko
   ```

3. Створіть і активуйте віртуальне середовище:

   ```bash
   python -m venv .venv
   # Windows (PowerShell)
   .venv\Scripts\Activate.ps1
   # Linux або macOS
   source .venv/bin/activate
   ```

4. Встановіть бібліотеки:

   ```bash
   pip install chromadb sentence-transformers ollama
   ```

5. Встановіть [Ollama](https://ollama.com/download) і завантажте модель генерації (близько 2 ГБ):

   ```bash
   ollama pull llama3.2:3b
   ```

6. Перевірте встановлення:

   ```bash
   python -c "import chromadb, sentence_transformers, ollama; print('ok')"
   ollama list
   ```

Модель ембедингів завантажується бібліотекою sentence-transformers автоматично під час першого використання. Версії бібліотек буде зафіксовано у файлі залежностей на етапі підготовки даних.

## Структура репозиторію

```
rag-project-sydorenko/
├── src/        вихідний код системи
├── config/     файли конфігурації
├── reports/    звіти з лабораторних робіт
└── README.md
```

У `src/` у наступних лабораторних з'являться підкаталоги для прийому даних, ембедингів, пошуку та оцінювання.

## Етапи проєкту

Кожна лабораторна робота фіксується тегом `lab-N`.

| Тег | Етап | Стан |
|---|---|---|
| `lab-1` | Проєктування: сценарій, корпус, стек, архітектура, репозиторій | виконано |
| `lab-2` | Збір і підготовка даних | заплановано |
| `lab-3` | Векторні представлення та індекс | заплановано |
| `lab-4` | Пошук і генерація | заплановано |
| `lab-5` | Тестування | заплановано |
