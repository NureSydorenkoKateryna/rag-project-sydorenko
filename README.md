## Сценарій використання

Читач пам'ятає сюжет, героїв чи окремі епізоди книжки, але не може згадати її назву й автора. Він описує книжку своїми словами, а система знаходить у корпусі найближчі описи та повертає назву, автора й уривок, що підтверджує відповідь.

Типовий запит: `A story about a group of boys stranded on an island who try to organise themselves and gradually turn savage`.

Обмеження системи:

- мова запитів, відповідей і корпусу лише англійська;
- один текстовий запит до 600 символів, діалог з уточненнями не передбачено;
- інтерфейс командного рядка, один запит дає одну відповідь;
- відповідь містить до трьох книжок, а для кожної назву, автора й рік (якщо вони є в записі) та уривок опису;
- система використовує лише відібрану підмножину корпусу, а якщо відповідного опису немає, повідомляє, що книжку не знайдено;
- рекомендації, оцінки книжок, пошук за обкладинкою чи цитатою з тексту та повні тексти книжок поза межами системи.

## Корпус даних

[CMU Book Summary Dataset](https://www.cs.cmu.edu/~dbamman/booksummaries.html) (D. Bamman, N. A. Smith, 2013). Це 16 559 книжок з описами сюжетів, назвою, автором, датою публікації та жанрами. Описи вилучено з Вікіпедії, метадані зіставлено з Freebase.

Для проєкту відібрано 9 216 книжок, у яких заповнені всі поля, а опис містить не менше 100 символів. Описи поділено на 20 609 чанків по 400 токенів із перекриттям 80 токенів. Докладніше в [data card](reports/lab-2/data-card.md).

Ліцензія даних: [CC BY-SA 3.0 US](https://creativecommons.org/licenses/by-sa/3.0/us/), як заявлено авторами набору. Похідні матеріали (відібрані документи, чанки) супроводжуються тією самою ліцензією, посиланням на джерело та описом змін, див. [data/processed/README.md](data/processed/README.md).

## Встановлення

1. Перевірте версію Python, потрібен 3.10 або новіший:

   ```bash
   python --version
   ```

2. Клонуйте репозиторій і перейдіть до його каталогу:

   ```bash
   git clone <URL_репозиторію>
   cd rag-project-sydorenko
   ```

3. Створіть і активуйте віртуальне середовище:

   ```bash
   python -m venv .venv
   # Windows (PowerShell)
   .venv\Scripts\Activate.ps1
   # Linux або macOS
   source .venv/bin/activate
   ```

4. Встановіть бібліотеки для підготовки даних:

   ```bash
   pip install -r requirements.txt
   ```

5. Встановіть бібліотеки наступних лабораторних робіт (індекс, ембединги, генерація):

   ```bash
   pip install chromadb sentence-transformers ollama
   ```

6. Встановіть [Ollama](https://ollama.com/download) і завантажте модель генерації (близько 2 ГБ):

   ```bash
   ollama pull llama3.2:3b
   ```

7. Перевірте встановлення:

   ```bash
   python -c "import chromadb, sentence_transformers, ollama; print('ok')"
   ollama list
   ```

Модель ембедингів завантажується бібліотекою sentence-transformers автоматично під час першого використання. Версії бібліотек підготовки даних зафіксовано у файлі `requirements.txt`.

## Підготовка даних

Команди виконуються з кореня репозиторію в активованому середовищі (PowerShell). Результатом є файл `data/processed/chunks.jsonl` з чанками.

1. Завантажте та розпакуйте початковий набір:

   ```powershell
   New-Item -ItemType Directory -Force data/raw | Out-Null
   curl.exe -L -o data/raw/booksummaries.tar.gz https://www.cs.cmu.edu/~dbamman/data/booksummaries.tar.gz
   tar -xzf data/raw/booksummaries.tar.gz -C data/raw
   ```

   Файл `booksummaries.txt` з'явиться в `data/raw/booksummaries/`.

2. Етап 1. Визначення кодування, очищення тексту, запис у JSONL (`data/interim/cleaned.jsonl`):

   ```powershell
   python src/ingestion/stage1_normalize.py --src data/raw/booksummaries/booksummaries.txt
   ```

3. Етап 2. Фільтрація записів (`data/processed/documents.jsonl`, 9 216 документів):

   ```powershell
   python src/ingestion/stage2_filter.py
   ```

4. Чанкування. Готовий файл `data/processed/chunks.jsonl` (20 609 чанків) і статистика `data/processed/chunk_stats.json`:

   ```powershell
   python src/ingestion/chunk.py --size 400 --overlap 80
   ```

5. За потреби підрахуйте найчастотніші слова корпусу (`data/processed/top_words.json`):

   ```powershell
   python src/ingestion/top_words.py
   ```

Для чанкування токенайзер моделі BAAI/bge-small-en-v1.5 завантажується з Hugging Face Hub, потрібне підключення до інтернету. Для Linux або macOS замініть команди першого кроку на `mkdir -p data/raw` і `curl -L -o ...`.

Усі параметри мають значення за замовчуванням і змінюються аргументами командного рядка (`--help`).

## Структура репозиторію

```
rag-project-sydorenko/
├── src/
│   └── ingestion/   підготовка даних: очищення, фільтрація, чанкування
├── data/
│   ├── raw/         початковий набір
│   ├── interim/     проміжний очищений корпус
│   ├── processed/   документи, чанки, статистика
│   └── experiments/ статистика порівняння параметрів чанкування
├── config/          файли конфігурації
├── reports/         звіти та data card
├── requirements.txt
└── README.md
```

У `src/` у наступних лабораторних з'являться підкаталоги для ембедингів, пошуку та оцінювання.
